Beyond One Prompt

Built to show agentic task delegation

This project separates research into distinct responsibilities instead of relying on one large chatbot prompt. The graph keeps a shared state, records a trace of agent decisions, retries fragile search work, and routes the task back to research when verification finds weak evidence.

Agent Team

Each agent owns one part of the job

01

Planner

Turns a broad goal into focused research questions that guide the rest of the workflow.

02

Researcher

Searches for source snippets, normalizes evidence, and records tool errors instead of crashing.

03

Analyst

Extracts themes, risks, and practical recommendations from the collected source material.

04

Verifier

Checks source coverage and can route the graph back to research when the evidence is thin.

05

Writer

Synthesizes the final report once the verifier approves the evidence or the round limit is reached.
